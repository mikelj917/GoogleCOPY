# Google Clone (Dark Mode) 🌙

Clone da interface da página de busca do **Google**, desenvolvido como exercício prático de HTML e CSS.

## 🎯 Objetivo

Reproduzir visualmente a **interface inicial de busca do Google**, aplicando um estilo **dark mode** para treinar habilidades de layout, espaçamento, tipografia e fidelidade visual.

## 🛠️ Tecnologias utilizadas

- HTML5  
- CSS3
